# 权柄分布

每个世界承载着独属于它的权柄集合——正如每片土地只长特定的树木。一条铁律横亘在所有世界之上：**一个世界同一时间只能有一位神占据神位**。加上纵贯一切的时间长河，"按理说"，宇宙中同一时刻只应有六个神位。

然而[[庭代尔·克罗蒂]]（暴君）与[[阿里昂]]（命运主），先后突破了这条铁律。他们一个来自人间，一个来自未来——都不是"按理说"应该存在的神。这是整个故事最深处的伏笔。

## 各世界权柄

| 世界       | 权柄                      |
| -------- | ----------------------- |
| **星之世界** | 真实、太阳、月亮、黑夜、审判、秩序、天穹、极光 |
| **物质世界** | 物质、风暴、烈焰、心灵、光之、斩、大地     |
| **灵之世界** | 灵魂、幻梦、智慧、故事             |
| **镜中世界** | 支配、无序、欲望、错误、悖论          |
| **亡者世界** | 死亡、轮回、亡者、生命             |
