# 子路

- **身份**：[[周公明]]的大弟子
- **修行**：巨力之术 + 医人奇术
- **性格**：心怀大义，正气浩然，不谙世事，直率果决

## 下山

公元 366 年，因见战乱四起、黎民哀嚎，虽被周公明告知"命不可违"，仍决意下山入世保无辜百姓。周公明赠予[[花间子母符]]（可受一次死劫）并说："若受第二次死劫，我手上母符会裂开，到时我会让人去收你的尸。"

## 结局

第一次死于乱军之手——被花间子母符复活。第二次**被乱军活活打死**。"他救了人，却救不了自己。" 他的死是促使周公明从"顺天"转向"逆天"的三根稻草之一。
