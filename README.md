# 帷幕 · The Curtain

《帷幕》是 iPas 持续创作的西方幻想世界。这个仓库保存世界设定、人物档案、编年史、短篇作品，以及相关互动网页的源码；同时也是可以直接打开的 **Obsidian 知识库**。

> 本库含人物身份、剧情走向和终局设定等完整剧透。部分设定仍在讨论，带有“待展开”或“待确认”标记的内容尚未定稿。

## 从哪里读起

- [帷幕总纲](帷幕总纲.md)：世界与故事的总入口。
- [阅读指南](阅读指南.md)：推荐阅读顺序与基础概念。
- [世界观](世界观/世界观总览.md)、[人物](人物/人物总览.md)、[魔法体系](魔法体系/魔法体系.md)、[编年史](编年史/编年史总览.md)：按主题浏览。
- [短篇](短篇.md)：已完成的故事。
- [创作工作台](工作台/创作工作台.md)：设定维护和创作进度。

GitHub 可以直接阅读 Markdown 正文；正文中的 Obsidian 双中括号内部链接、Dataview 表格和部分样式需要在 Obsidian 中查看。

## 用 Obsidian 打开

1. 下载仓库 ZIP 并完整解压，或克隆本仓库。
2. 在已安装的 Obsidian 中选择“打开已有仓库”，选择包含本 README、`.obsidian` 和 `帷幕总纲.md` 的文件夹。
3. 从《帷幕总纲》开始阅读。若要使用 Dataview 与 Juggl，在“设置 → 第三方插件／社区插件”中确认信任此知识库，然后启用插件。

仓库保留共享设置、CSS、Dataview、Juggl 和 Fancy-a-Story 主题，供跨设备恢复使用。插件与主题的版本要求及来源见 [Obsidian 配置说明](docs/Obsidian配置.md)。普通 Markdown 阅读无需启用插件。

## 跨设备同步

本仓库使用 Git 保存版本，不会自动上传修改。另一台电脑可运行：

```sh
git clone https://github.com/iPassione/curtain-obsidian-vault.git
```

编辑前先拉取，编辑完成后提交并推送；详细步骤见 [跨设备同步](docs/跨设备同步.md)。两台机器各自保留 Obsidian 窗口布局，避免打开状态互相覆盖。
