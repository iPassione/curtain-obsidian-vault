# 权柄

权柄是半神与真神的力量核心——对自然法则某一侧面的终极掌控。它不是学来的，不是练出来的。它是征服得来的。

## 特性

- **天然存在**：权柄并非由修士凭空发明，而是自然法则中既有的“节点”。它可能被掌握，也可能空置。
- **独一性**：同一时刻，一个权柄只能被一人掌握。这是写入世界底层逻辑的铁则。前任死亡，权柄方才回归自然，等待下一个征服者。
- **复现难度**：曾经被前人掌握过的权柄，可能因留下经验与路径而更容易被后人复现；但这仍远不足以稳定量产半神。
- **来源**：权柄由"显化核心碎片"与施法载体融合而成——前者是将抽象概念凝为具象碎片的奇迹，后者是晋升者一生中须臾不离的亲密法器。详见[[半神晋升]]。
- **分布**：不同的权柄归属于不同的[[六大世界]]。世界的先天属性，决定了其中可能诞生怎样的权柄。详见[[权柄分布]]。

## 权柄 → 神格 → 神位

掌握一个权柄，便获得神格——由此成为**半神**。掌握两个相契合的权柄，便能将神格熔铸为神位——由此成为**真神**。三个步骤，一步比一步艰险。

第二权柄的“契合”不是主观搭配，而是**先天共鸣**。候选组合必须能共同指向一个世界的底层核心。任何权柄理论上都可能成神，但真正的瓶颈在于：是否有合适的第二权柄，以及持有者本人是否能等到并抓住那个极其罕见的“时代之需”。


## 支配与主宰

在帷幕世界的半神中，有两个权柄的名字时而被并提、时而被混淆——"支配"与"主宰"。它们的区别，是这个魔法世界最精妙的分界线之一。

|        | 支配之神（[[提亚纳斯·克罗蒂]]）   | 主宰之神（[[庭代尔·克罗蒂]]）      |                     |
| ------ | -------------------- | ---------------------- | ------------------- |
| 来源世界   | [[六大世界#镜中世界          | 镜中世界]]                 | 五界之和——庭代尔从多个世界汲取了养分 |
| 核心作用域  | **人**——身体、灵魂与心灵      | **自然**——权柄、法则与力量       |                     |
| 对人的效果  | 修改认知、改变意志、扭曲心灵       | 以恐怖威压令一切臣服             |                     |
| 能否操纵意志 | **能**——言出法随，意志不再属于本人 | **不能**——只能施加不可抗拒的震慑    |                     |
| 能否征用权柄 | 不能                   | **能**（半神时期有上限，真神后突破界限） |                     |
| 对半神的效果 | 打折扣但仍有效；配合造物/蕴法石可致命  | 取决于征用的权柄和熟悉程度          |                     |

"支配"更像是催眠——声音是媒介，但实质是混杂在声波震动中的魔力。它不是命令耳朵，是命令灵魂。

"主宰"则是另一条路径。主宰之神不试图修改你的意志——他让你自己跪下。他不占你的灵魂——他征用自然的权柄来代替你的神格。他不需要你的服从——他让万物替他说话，而你只能听着。
