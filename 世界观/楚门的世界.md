# 楚门的世界

[[法德利·克罗蒂]]在伦敦为[[达里安·霍夫科特]]编织的**长达九年的虚假人类人生**。

## 名称由来

neta 电影《楚门的世界》——达里安在其中生活了 16 年，却不知道身边的一切都是被精心安排的"舞台"。

## 运作方式

- 2016 年，半神[[西里斯]]将 7 岁的达里安托付给法德利
- 法德利在伦敦开办"超自然侦探事务所"作为掩护
- 雇佣演员扮演达里安的"父母"与"妹妹"
- 篡改了达里安的记忆，让他以为自己是一个普通的伦敦高中生
- 目的：让达里安的命运不被[[永夜教会]]和[[羽蛇]]发现，平安长大

## 事务所成员（表面 vs 真实）

| 成员      | 表面身份     | 真实                     |
| ------- | -------- | ---------------------- |
| 法德利     | 落魄法师老板   | 真神遗孤，幕后导演              |
| [[格罗]]  | 柔弱女巫专员   | [[切西娅]]间谍（受[[赫法恩斯]]操控） |
| [[卡列斯]] | 街头魔术师    | 前[[羽蛇]]杀手（Lv.7）        |
| [[奎克拉]] | 法德利的知己兄弟 | 源溯级，第一卷战死              |

## 破碎

正传第一卷：安全网被暴力撕碎——卡列斯与奎克拉战死。法德利带着达里安逃离伦敦，正式回归帷幕世界。
