# 菩提

[[周公明]]在公元 385 年陨落前，将自身全部力量——包括轮回神格、一丝"命运"和[[七生七死创世符]]——封存进的一颗菩提子。是连接东方道法与西方魔法世界的关键道具。

菩提子中封存的，不止是周公明一人的力量。[[万物主#第四世|第四世]]——那位成为死亡之神的转世——在濒死之际将自身回路凝为第四颗菩提珠，送归物质世界，重归青城山。菩提是七世道果的容器，每一颗珠都是一条走完的路。

## 历史流转

1. **385 AD**：[[周公明]]陨落，将前四世道果凝为菩提，留在[[青城山]]
2. **1973 年**：[[庭代尔·克罗蒂]]在北海找到菩提——这颗东方至宝不知为何出现在西方世界的北海深处
3. **1976 年**：庭代尔凭借菩提平衡心智，登临真神
4. **1976 年**：菩提中的周公明苏醒，与庭代尔定下"再造神国"计划
5. **1995 年**：庭代尔临终前将菩提归还[[青城山]]（具体方式待设定）
6. **正传第一卷**：[[达里安·霍夫科特]]将获得菩提（获取方式待定）

## 能力

- 平衡心智，防止力量暴走
- 蕴藏轮回+命运神格碎片
- 连接东方道法与西方魔法的桥梁
- 只有周公明的转世（达里安）能完全激活
