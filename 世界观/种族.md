# 种族结构

帷幕世界的居民由**巫师、亚人（亚种）**与混血种共同构成。帷幕之内没有纯粹的人类。所有居民——巫师、亚人、混血种——从降生的那一刻起便拥有魔法回路。帷幕世界是魔法生物的世界，“凡人”仅存在于帷幕之外的人类旧土，或作为相对于神明的修辞。**

## 亚人：帷幕的原住民

在巫师到来之前，帷幕之下已有居民。"亚人"是一个笼统的泛称——精灵、作为天使原型的翼人、栖居水中的半鱼人……种类繁多，多数种群人数不多。他们的外貌与巫师、人类相差之大，使得他们早早便迁入帷幕聚居，以躲避人类世界审视的目光。

巫师大迁徙来临时，两边的关系一度紧绷。巫师并不总是讲道理的。直到[[魔法联合部]]建立后，双方才逐渐走向和解——如今算是和平共处，虽然裂痕从未真正愈合。

## 巫师与亚人的本质区分

| | 巫师 | 亚人 |
|---|---|---|
| 回路 | 可塑性强，可以不断重塑与进化 | 结构固定，天生亲和某种特定体系 |
| 力量来源 | 可能性 | 血脉 |
| 前期 | 弱 | 天然优势明显 |
| 后期 | 上限极高 | 发展空间有限 |
| 与自然的关系 | **借用 / 外部沟通者** | **归属——自身即自然的一部分** |
| 施法媒介 | 需要魔杖导出 | 无须魔杖，可直接施法 |
| 成就上限 | 理论上可达神位 | 难以掌握[[权柄]] |

亚人难以成神的根源，不在于天赋不足，而在于他们与自然的关系本身就是一道阻碍。自然的象征会将亚人视为自然的一部分——既然是自然本身，便无从"征服"自然。而征服，恰恰是获取权柄的前提。

不过这并非绝对。亚人中同样出过成神者，只不过极其稀少。血脉是礼物，也是牢笼——而巫师没有牢笼。

## 失言者：回路断绝之人

巫师家庭中偶有降生即无魔法回路的婴儿——这就是失言者。“失言”二字取自其无法咏唱咒文、无法与自然力量共鸣的处境。他们是帷幕鄙视链的最底端：贵族家庭若出了失言者，心狠者会直接处死，氛围稍好的家族也会将其终生藏匿。失言者没有社会身份，不存在于任何官方记录中。他们终生困于府邸后院或地下密室，是帷幕世界最沉默的阶层。

## 已知亚种种族

- 赛特斯族——[[厄尼西姆]]的种族，[[万物主]]以自身信仰种下的海岛亚人，信仰死亡却热爱生命
- 翼人族——[[加利贝尔]]的种族，天使的原型
- 质人族——[[普里多尼]]的种族，天生亲和物质，擅长炼金
- 半羊人族——[[赫法恩斯]]的种族
- 月人族——[[切西娅]]的种族，魅魔的原型
- 星中人——[[塞浦路斯]]的混血来源之一
