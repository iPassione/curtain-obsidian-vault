# 蕴法石

蕴法石是帷幕世界最重要的魔法矿物资源——**能贮存完整咒语并一次性施放的矿物**。它既是巫师们的战略物资，也是整个帷幕经济的底层支柱之一。

## 一句话定义

**能贮存咒语并一次性施放的矿物。**

## 与造物的区别

|      | 造物             | 蕴法石       |
| ---- | -------------- | --------- |
| 存储内容 | 初步塑形的魔力        | 完整的咒语     |
| 对应效果 | 某种持续性"特点"或"效果" | 精确的单次咒语释放 |
| 可否恢复 | 可自然恢复，可重复使用    | 一次性，用完即止  |
| 本质比喻 | 可持续使用的魔法工具     | 单次引爆的魔法子弹 |

造物是工具——你带着它，它陪伴你。蕴法石是弹药——你用掉它，它消失。

## 核心特性

- 可贮存**完整的咒语**（区别于造物存储的初步塑形魔力）
- 将储存的咒语以**无损耗**的效果重新释放
- **一次性**——一旦用过，不可再往里存咒语。这是魔法联合部通过《蕴法石管制法案》时写在第一条的底线：如果蕴法石可以反复充能，半个世界的经济结构会在五年之内崩塌

## 体积与容量的关系

- 体积大小**只与贮存咒语数量有关**，与咒语等级高低无关
- 咒语的体量决定其占用体积——复杂咒语天然占用更多石材，简单咒语只占一部分，剩余部分可以继续使用
- 因此不存在固定的"最低可利用规格"上限——再复杂的咒语出现，只是意味着需要找一块更大的石头

一个拳头大小的蕴法石可能只装得下一道启明级的照明咒，也可能装不下一道源溯级的广域防御。不是魔力的层级限制了它——是咒语的复杂程度决定了它在石头里占据多少空间。

## 多咒语混入的问题

- **物理层面**：蕴法石在被充满之前，可以吸收不同咒语
- **使用层面**：一块完整的石头只能释放**同一个咒语**。不同咒语混入会互相影响、互相抵消——就像在一张纸上反复写字，最终谁也读不出来

## 废石的价值

用过的蕴法石不能再填充咒语。但它的故事没有结束。

废石内部结构因承载过魔法而发生微妙变化——在某些特殊用途上，它比一块从矿坑里挖出来的普通石头更有价值：

- **建材**：曾承载过防御性咒语的废石，其结构残余可在建筑中提供被动防护
- **研磨料**：用于铸造魔法中某些特殊工具的加工
- **炼金原料**：少量交易，部分炼金师声称废石是某些特定配方中不可替代的成分

由此形成**二级市场**——废石买卖并不大，但它存在着，养活了一小批以此为生的中间商。

## 工业用途

大块蕴法石作为工业能源，本质上是一座**咒语弹匣**。预存大量同一咒语，机器每次调用消耗一发，连续释放形成持续能源效果。大块解决的是**续航**问题，而非单次威力——一块磨盘大的蕴法石不能打出半神级的攻击，但它可以让一台铸造车间的炉子烧上三个月。

## 禁魔石时代（历史趣闻）

在远古时代，蕴法石曾被当作"禁魔石"使用。

古人发现这种石头能吸收咒语，但他们不知道它还能把咒语释放出来。在他们眼中，这是一件能"吃掉"魔法的矿物——天然的防具。于是有人把它嵌在盾牌上、镶在城门上、甚至碾碎涂抹在城墙上。但由于石头过于笨重，且不方便开采，这种方法未曾大规模普及。

几千年后，当一个记不清名字的巫师不小心触发了自己几百年前封进去的那道咒语——整个魔法史翻过了一页。
