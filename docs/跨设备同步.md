# 跨设备同步

## 首次使用另一台电脑

安装 Git 并登录有仓库写入权限的 GitHub 账号。选择一个未占用的目录，再克隆：

```sh
git clone https://github.com/iPassione/curtain-obsidian-vault.git
```

在 Obsidian 中把克隆出的文件夹作为已有仓库打开。不要将它克隆进另一份现有知识库内部。若已有同名资料，使用新的空目录，保留原文件。

## 每次编辑

先在仓库目录拉取：

```sh
git pull --ff-only
```

完成编辑后：

```sh
git status
git add -A
git commit -m "补充本次设定"
git push
```

这些命令只在手动执行时同步。每次切换设备前，确保当前设备已推送；另一台机器编辑前先拉取。

若拉取提示本地修改或分支分歧，先保留本机内容并检查差异，再合并；不要直接覆盖文件或强制推送。同步后若 Obsidian 界面未刷新，可重新打开相关笔记。

## 同步范围

同步全部主题笔记、附件、网站源码、插件、主题和共享配置。设备窗口布局、缓存、回收站、临时文件、凭据及 `导出/` 不同步。导出文件需在另一台机器按需重新生成，或单独传输。
