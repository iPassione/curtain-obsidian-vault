# 仓库维护

## 内容放置

- 世界规则、人物、魔法和历史分别放入现有主题目录；优先维护已有笔记。
- 索引保留在总纲、阅读指南与各主题总览中。Obsidian 内链优先使用唯一的笔记名称。
- 游戏构想放在 `游戏企划/`；互动网页、角色网站与分析报告放在 `衍生项目/`。
- 分享压缩包、单文件网站导出等放在本机 `导出/`，不进入后续版本。
- 共享阅读配置、插件、主题与必要素材保留跟踪。不要提交账户凭据、缓存或设备窗口布局。

移动笔记时同步修复显式路径；移动网页时保持素材相对目录，避免图片和脚本失效。所有待定设定应显式标记，剧情与规则的实质变更须由作者确认。

## 忽略规则

`.gitignore` 排除设备状态、系统杂项、临时文件、环境凭据、依赖安装目录、构建目录和导出包。忽略规则只影响后续跟踪，不会移除历史提交里的文件。

本次整理前已跟踪的分享 ZIP 和单文件网站导出已停止跟踪，本机副本保留在 `导出/`。历史记录仍可恢复整理前版本。

## 提交

提交前查看 `git status` 与差异，使用说明具体变更的提交信息。修改世界设定时同步维护相关导航；第三方组件升级时记录版本并检查其要求。
