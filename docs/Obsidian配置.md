# Obsidian 配置

`.obsidian` 中保留共享配置、模板设置、CSS、插件和主题，使克隆后的知识库能够延续现有阅读体验。设备窗口布局与缓存由 `.gitignore` 排除。

| 组件 | 仓库内版本 | manifest 声明的最低 Obsidian 版本 |
| --- | --- | --- |
| Dataview | 0.5.68 | 0.13.11 |
| Juggl | 1.5.0 | 1.4.16 |
| Fancy-a-Story | 2.7.4 | 1.13.0 |

版本要求取自仓库内组件清单，不代表已在所有系统验证。要使用全部样式，建议使用至少满足主题要求的 Obsidian 版本。

Dataview 用于工作台动态表格，Juggl 提供关系图，Fancy-a-Story 与 `snippets/Curtain.css` 提供显示样式。若不启用社区插件，Markdown 正文仍可阅读。

首次打开时，在“设置 → 第三方插件／社区插件”确认信任，再启用 Dataview 和 Juggl。主题在“设置 → 外观”选择，CSS 片段也在外观设置中启用。不同 Obsidian 版本的菜单措辞可能不同。
