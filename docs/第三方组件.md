# 第三方组件

本仓库为恢复 Obsidian 阅读体验及角色网站显示效果保留部分第三方组件。它们不属于《帷幕》原创设定，各自的版权和许可证继续适用；本说明不替代组件原有声明，也不额外授予使用权。

| 组件 | 位置 | 来源 |
| --- | --- | --- |
| Dataview | `.obsidian/plugins/dataview/` | https://github.com/blacksmithgu/obsidian-dataview |
| Juggl | `.obsidian/plugins/juggl/` | https://github.com/HEmile/juggl |
| Fancy-a-Story | `.obsidian/themes/Fancy-a-Story/` | 作者 ElsaTam；仓库内 manifest 的作者主页为 https://github.com/ElsaTam |
| GSAP、ScrollTrigger、ScrollToPlugin | `衍生项目/庭代尔个人站/assets/vendor/` | https://gsap.com/ |
| Lucide | `衍生项目/庭代尔个人站/assets/vendor/` | https://lucide.dev/ |
