# 青城

- **时代**：公元 366 年，蜀地青城山七星观
- **视角**：[[周公明]]与三位徒弟[[子路]]、[[子彦]]、[[子夏]]

## 核心情节

1. **子路下山**：心怀大义欲保无辜百姓——周公明告知"命不可违"但最终放手，赠[[花间子母符]]
2. **子彦下山**：为回乡完婚——周公明同样赠符："为师便以此提前祝你新婚喜乐。"
3. **子夏留下**："子夏无父无母，自幼在观中长大，所以无心下山，只愿长留在周师身畔。"
4. **收留赵根**：难民祖孙——祖母为让孙儿入观，撕碎衣袖推开孙子，下山三天后饿死路边
5. **周母之墓**：周公明带子夏到母亲坟前，讲述自己的"命运"一课——母亲吃丹药治好痨病却被天雷劈死

## 关键台词

- "弟子愚笨，但私以为既有救世之能，不予作为便是罪过。"——子路
- "在这观里，我就是规矩。"——周公明
- "况且，总得给他们家留个种吧？"——周公明（收赵根）

## 文学功能

- 为整个世界的东方因果脉络打底
- 建立周公明"顺应天道"→"怒而逆天"的性格弧光起点
- 引入[[赵根]]作为东西方魔法的连接桥梁
- 花间子母符的起源
