# 设定维护规则

## 单一事实来源

- 正典以具体设定笔记为准，总纲和工作台只负责导航与汇总。
- 同一事实不要在多个页面重复扩写；其他页面用链接和一句话摘要引用。
- 分析报告、游戏企划和个人站属于衍生内容，不自动反向修改正典。

## 最小属性规范

新笔记优先使用 [[人物模板]]、[[事件模板]]、[[组织模板]] 或 [[短篇模板]]。

| 属性 | 用途 | 推荐值 |
|---|---|---|
| `tags` | 主题和归属 | 人物、世界观、短篇、编年史、组织等 |
| `aliases` | 别名、译名、称号 | 只写实际会用于链接或搜索的名称 |
| `status` | 设定成熟度 | 已确认、待展开、草稿、争议 |
| `era` | 所属年代 | 具体年份或编年史阶段 |
| `faction` | 人物/事件所属势力 | 使用带引号的内部链接 |
| `created` | 创建日期 | `YYYY-MM-DD` |

不强制回填全部旧笔记。需要编辑某篇旧笔记时再顺手补齐，避免一次性元数据迁移制造大量噪音。

## 状态约定

> [!canon] 已确认
> 已由作者明确确认、可作为后续创作依据的内容。

> [!foreshadow] 伏笔
> 已确认存在，但当前不应向读者完整揭露的内容。

> [!question] 待展开
> 方向存在，细节尚未定稿，不应被下游笔记当作硬约束。

> [!conflict] 冲突
> 与其他已确认设定不一致，必须先解决再继续扩写。

## 链接与归档

- 每篇正典笔记至少应被一个 MOC、人物页或事件页引用。
- 新人物优先链接其所属组织、关键关系和首次出场事件。
- 新事件至少链接参与者、地点、原因与后果。
- 导出文件、压缩包和网站构建产物不作为正典资料；后续统一迁入专门的导出目录或移出 vault。
