# 帷幕模拟人生 · 开发方向与技术报告

> 舞台：卡莫瑞亚中心城市 **普诺伊瓦**
> 玩法参照：《中国式家长》（养成 + 事件）与《模拟人生》（生活 + 职业）
> 调性：轻松向文字游戏
> 状态：企划初稿 · 待拍板后进入原型

## 一句话结论

**先做「仿《中国式家长》的单角色养成文游」作为 MVP，把《模拟人生》的开放沙盒降级为远景目标。** 技术用**数据驱动（JSON）+ 网页前端**，与 vault 里已有的 HTML 交互件（圣德赛尔测验、庭代尔个人站）同一条路线，便于长期在 Obsidian 里维护和发布。

---

## 一、游戏定位

玩家扮演普诺伊瓦城里一个普通巫师（或亚人）家庭的孩子，在「上学 → 练咒 → 社交 → 打工 → 应付家庭/联合部」的日常里长大，通过安排日程和选择事件，走向不同的人生结局。

- **核心循环**：每回合（周/月）安排日程 → 消耗精力/心情/索比恩 → 触发剧情事件 → 数值变化 → 阶段检定（升学、就业、意外）。
- **情绪基调**：轻松日常 + 英式冷幽默（卡莫瑞亚的「世界之尺」优越感 vs 全大陆最差美食）。世界观的正剧悲剧只做**背景板与彩蛋**，不压主线。

---

## 二、三个方向对比（先选一个做）

| 方向 | 玩法内核 | 优点 | 缺点 | 适合 |
|---|---|---|---|---|
| **A. 养成线（推荐 MVP）** | 仿《中国式家长》：日程表 + 数值养成 + 事件卡牌 + 结局 | 文本量可控、循环明确、出 demo 快 | 自由度低、重复感需靠事件库缓解 | 首发 |
| B. 生活沙盒 | 仿《模拟人生》：职业/社交/房产/造物自由推进 | 耐玩、符合「普诺伊瓦最大都会」的舞台感 | 内容量指数级，单人或小团队容易烂尾 | 中后期 |
| C. 轻量叙事 | 互动小说：固定主线 + 选项分支 | 最快、最好讲故事 | 重玩性弱、可扩展性差 | 作为 A 的「新手引导/序章」复用 |

**建议路线**：先做 C（约 3–5 个事件的一段序章）验证文本风格和世界观调性 → 再扩成 A 的完整养成循环 → B 只在 A 稳定后作为资料片。三个方向共享同一套「人物数值 + 事件数据」结构，不会白做。

## 三、技术方案

### 推荐：数据驱动 + 网页前端

- **结构**：静态 HTML/CSS/JS（或 Vue/React）作为外壳；所有剧情、事件、职业、结局放在 **JSON/表格数据**里，游戏运行时读取。
- **理由**：
  1. vault 已有 `圣德赛尔五年级魔法史摸底测验.html`、`魔法体系适配测试.html`、`庭代尔个人站` 等 HTML 交互件，作者已熟悉这条路线，Obsidian 可直接打开/预览。
  2. 文字游戏的瓶颈是**内容量**而非引擎性能；把内容写成数据，作者后续可以在 Obsidian 里用 Markdown 或表格直接增补事件，不必动代码。
  3. 可维护、可迁移：未来要上手机或做成 App，数据层可原样迁移。

### 备选引擎（按需升级）

| 引擎 | 适合场景 | 说明 |
|---|---|---|
| **Twine / Ink** | 纯叙事、最快出故事 | 适合方向 C；但数值养成（A）要自己搭，不如自定义 |
| **Ren'Py** | 需要立绘 + 多平台 + 存档 | 适合有 CG/语音的视觉小说向，偏重 |
| **Godot** | 想做带地图/动画的 2D 养成 | 上限最高、成本也最高，MVP 阶段不建议 |

### 存档与发布

- MVP 阶段用浏览器 `localStorage` 存单机存档即可。
- 发布形式：单文件 HTML 放进 vault / 分享 zip，与现有个人站一致。

## 四、世界观落点（哪些直接用、哪些要补）

### 可直接进游戏的现成设定

- **普诺伊瓦**：帷幕世界最大都会、魔法联合部总部、界门枢纽、英式秩序、官僚气息、全大陆最差美食（最出名的餐厅是埃斯佩兰萨人开的烤肉店）——这是天然的「城市舞台 + 笑点来源」。
- **货币**：索比恩 ≈ 1 人民币（生鸡蛋 ≈ 1 索比恩），100 索比恩 = 1 铜加令。经济系统可以直接按「索比恩」标价，手感接近现实物价，玩家零学习成本。
- **巫师等级**：启明(Lv1) → 灵犀(2) → 织法(3) → 律痕(4) → 源溯(5)… 前四级是普通巫师，正好覆盖养成全程；Lv4 是「人之终」，可作顶级毕业目标。
- **魔法体系**：基础魔法（门槛低、天花板 Lv3）+ 38 种高级魔法（Lv4 起）。养成里「选专精体系」是天然的分支点。
- **施法四阶段**：起势 → 塑形 → 稳定 → 导出；无声施法/无杖施法可做成「高难挑战成就」。
- **魔杖**：短杖是现代标准，与主人形成「默契」。可做「魔杖契合度」养成维度。
- **种族**：巫师（可塑回路）vs 亚人（固定回路、天生亲和某体系）vs 失言者（无回路、社会最底层）。可选种族/出身，直接产生不同玩法和难度。
- **职业生态**：联合部官僚、圣律造物登记、造物师/魔药师、教团、裁决执行处（辛克莱尔等）、贵族、界门商贸——职业结局池已经很丰富。

### 需要作者拍板/补写的空白

1. **圣德赛尔魔法学院**：笔记明确标注「待补充」，校址、学制、入学制度都没有。而养成游戏几乎绕不开学校——**这是最高优先级的设定缺口**。
2. **普诺伊瓦的日常生活细节**：现有设定偏政治/经济宏观，缺少街道、店铺、节庆、食物、居民职业等「烟火气」。轻松向文游最吃这个，建议边做边补并**回写 vault**。
3. **时间线锚点**：正传是 2025+ 伦敦、前传暴君时代 1947–1990、过渡期 1995–2025。游戏选哪个年代，直接决定会不会撞上历史大事件。**建议避开正传主线，选一个「安全窗口」（如过渡期或平行 if 线）**，把暴君、殉道等悲剧降级为街头传闻。
4. **失言者**：设定是被藏匿/处死的悲剧阶层，与「轻松向」冲突。建议**不作为默认可选出身**，只做隐藏困难路线或后期彩蛋。

## 五、体量与侧重判断

### MVP（单人，约 3–6 个月）

- 1 个可用出身（普诺伊瓦平民巫师家庭）＋ 1 条主线（上学到毕业/就业）。
- 日程表养成 + 20–40 个事件 + 5–8 个结局。
- 文本量约 **5–10 万字**；代码量小，重点在事件库。
- 目标是「能完整玩通一遍、有 2–3 次重开动力」。

### 完整版（单人，约 6–12 个月）

- 多出身（平民/官僚/贵族/亚人，失言者作隐藏）+ 多专精体系 + 多周目。
- 事件 100+、结局 15+，加入简单的社交网与职业线（B 方向雏形）。
- 文本量约 **20–50 万字**。

### 侧重建议

1. **重内容、轻引擎**：90% 的时间花在写事件和调数值，引擎只求「改数据不用动代码」。
2. **先竖切一条完整纵向流程**（出生→童年→上学→毕业→一个结局），再横向铺事件，避免「事件很多但串不起来」。
3. **把世界观回写进 Obsidian**：游戏里新造的人物、店铺、节庆，同步落到 `Y:\Obsidian\帷幕` 对应目录，保持 vault 单一事实来源，避免游戏内容与正典脱节。
4. **轻松向的边界**：喜剧集中在卡莫瑞亚的傲慢、官僚僵化和美食荒漠；涉及命运、牺牲、失言者的悲剧，只做远景背景和隐藏彩蛋，不做主线冲突。
